# Eniolami Saheed — Portfolio

Professional portfolio for Eniolami Saheed, a content strategist, social media manager and community manager.

## What is included

- Selected client case studies and verified performance results
- Professional experience and content samples
- Responsive desktop and mobile layouts
- Recruiter-ready downloadable CV
- Vercel configuration for React Router routes

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist`.

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Select **Vite** as the framework preset.
4. Use `npm run build` as the build command.
5. Use `dist` as the output directory.
6. Deploy.

No environment variables are required for the public portfolio.
